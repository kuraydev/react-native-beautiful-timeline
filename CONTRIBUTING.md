# Contributing

Thanks for your interest in improving **react-native-beautiful-timeline**! 🎉

## Development setup

```sh
git clone https://github.com/kuraydev/react-native-beautiful-timeline.git
cd react-native-beautiful-timeline
npm install
```

The library source lives in `lib/`. The bundled output (`dist/`) is generated by
[`react-native-builder-bob`](https://github.com/callstack/react-native-builder-bob)
and is **not** checked in.

## Scripts

| Script | What it does |
| --- | --- |
| `npm run typecheck` | `tsc --noEmit` over `lib/` |
| `npm run lint` | ESLint (flat config, `eslint.config.mjs`) |
| `npm run format` | Prettier write |
| `npm run format:check` | Prettier check (used in CI) |
| `npm test` | Jest + `@testing-library/react-native` |
| `npm run build` | Build CJS + ESM + types into `dist/` |

Please make sure `typecheck`, `lint`, `format:check`, `test`, and `build` all pass
before opening a pull request — CI runs the same set on Node 18 and 20.

## Backward compatibility

This is a published library with real dependents. **Do not** change:

- the npm package name,
- the default export,
- public prop names (`data`, `timelineStyle`, `dateFormat`, `*TextStyle`,
  `dayTextStyle`, `monthTextStyle`, `innerContainer`, `outerContainer`, forwarded
  `Dash` props),
- the `ITimeline` / `ITimelineData` data shape,
- runtime default values (e.g. the default `dateFormat` of `"DD ddd, HH:mm"`),

without a documented **breaking change** and a major version bump.

## Commit messages

We use [Conventional Commits](https://www.conventionalcommits.org/) (enforced by
commitlint): `feat:`, `fix:`, `docs:`, `chore:`, `refactor:`, `test:`, `perf:`,
`ci:`, `style:`, `revert:`.

## Pull requests

1. Branch off `master`.
2. Add/adjust tests for your change.
3. Update `CHANGELOG.md` under `## [Unreleased]`.
4. Fill out the PR template, including any breaking changes.
